# GlowUp AI — демонстрационный веб-проект

Готовый адаптивный одностраничный прототип сайта GlowUp AI.

## Что внутри

- Главная страница и позиционирование проекта.
- Блок «Как работает».
- Пять направлений: спорт, осанка, уход, стиль, привычки.
- Пять AI-помощников.
- Интерактивные реакции помощника:
  - успех — Алекс поднимает руки и показывает мышцы, появляются звёзды;
  - неудача — мягкая анимация и поддерживающая фраза без негативной оценки.
- Демо личного кабинета и прогресса.
- Модальное окно загрузки фотографии.
- Локальный мини-разбор без отправки файла на сервер.
- Адаптация для компьютера, планшета и телефона.

## Запуск

Откройте файл `index.html` двойным щелчком в браузере.

Для локального сервера можно выполнить:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Структура

- `index.html` — разметка.
- `styles.css` — дизайн и анимации.
- `app.js` — интерактивность.
- `PROJECT_SPEC.md` — структура дальнейшей разработки.

## Важно

Это интерфейсный прототип. Реальный AI-анализ фото, авторизация, оплата,
база данных и хранение прогресса требуют серверной части и подключения модели.
